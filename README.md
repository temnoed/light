# Light — фонарик под музыку

Android-приложение: слушает микрофон, вспыхивает вспышкой на бас и меняет
яркость светодиода в соответствии с высотой тона.

## Что внутри

- **Kotlin + Jetpack Compose**, minSdk 26, target/compile SDK 34.
- **AudioRecord** (44.1 кГц, моно, PCM 16 бит) → БПФ 2048 →:
  - детектор бита по пикам **общей громкости** (RMS): главный признак —
    резкий рост уровня за кадр (атака), плюс порог по шумовому полу и среднему
    уровню за ~0.9 с; затухающий хвост не считается (гистерезис). Низкие
    частоты больше не обязательны — вспышка реагирует на самые громкие пики
    музыки;
  - доминирующая частота 60–1800 Гц → яркость по логарифмической шкале 80–1400 Гц.
- **Вспышка**:
  - Android 13+ и драйвер с `FLASH_INFO_STRENGTH_MAXIMUM_LEVEL > 1` —
    аппаратная плавная яркость (`turnOnTorchWithStrengthLevel`);
  - иначе ШИМ фиксированной частоты **80 Гц** (`setTorchMode`), скважность =
    яркость. Частота не настраивается: 80 Гц — компромисс между незаметным
    мерцанием и нагрузкой на светодиод.
- **Две независимые кнопки**: «Фонарик» (вспышка) и «Экран» (свет самого
  экрана). Можно включить любую или обе сразу; выключение одной не гасит другую.
- **Один ползунок** «Чувствительность» (×0.4…×3.0) — единственная настройка,
  меняется на лету.
- Экранный свет плавно следует за тоном и добавляет всплеск на бит — на IPS-экране
  это ровная яркость без мерцания.
- **Встроенный тест бита**: телефон сам играет 16 басовых ударов в темпе
  120 BPM через динамик (громкость медиа на время теста поднимается до 100 %
  и потом возвращается), а микрофон их считает. В карточке «Тест бита» видно,
  сколько ударов поймано, какой темп измерен и какая была максимальная
  громкость/энергия баса, — весь тракт проверяется без внешней колонки.
- **Надёжная остановка**: каждая кнопка гасит свой источник, а микрофон
  освобождается, когда выключены обе; всё выключается также при уходе
  приложения в фон (`onPause`/`onStop`) и при закрытии.
  `AudioRecord` освобождается принудительно, поэтому индикатор микрофона не
  остаётся висеть.

## Как это должно ощущаться

- **Фонарик** — вспышка строго по ударам баса; яркость в пределах удара зависит
  от высоты тона. На C31 LED работает on/off, поэтому картинка «строб».
- **Экран** — ровная белая подсветка, которая следует за тоном; на IPS C31 без
  мерцания, в отличие от ШИМ вспышки.
- Обе кнопки можно держать включёнными: вспышка бьёт по басу, экран светит
  ровно и добавляет всплеск на удар.

## Сборка

Нужны JDK 17 и Android SDK с платформой 34. Всё это на этом ПК уже есть.

```powershell
cd E:\Light
.\gradlew.bat assembleDebug
```

APK появится в `app\build\outputs\apk\debug\app-debug.apk`.
Первый запуск `gradlew` скачает сам Gradle 8.9 (~130 МБ), дальше сборка идёт офлайн.

Готовый debug-APK уже собран в этом проекте.

## Установка на телефон (Android 13)

1. Включите «Для разработчиков» и «Отладка по USB».
2. Подключите телефон кабелем и разрешите отладку.
3. Проверьте, что устройство видно:

```powershell
adb devices
```

4. Установите:

```powershell
adb install -r app\build\outputs\apk\debug\app-debug.apk
```

Либо просто перенесите APK на телефон и откройте файл (понадобится разрешение
«Установка из неизвестных источников»).

## Первый запуск

- Разрешите **микрофон** (обязательно) и **камеру** (нужна для доступа к
  характеристикам вспышки и аппаратной яркости).
- Поднесите телефон к колонке микрофоном, включите музыку, нажмите
  «Фонарик» (вспышка) и/или «Экран» (свет экрана).
- Начните с чувствительности ×1.0; если бит не ловится — увеличьте,
  если срабатывает на всё подряд — уменьшите. Ползунок действует сразу,
  перезапускать свет не нужно.

## realme C31 (Android 13, realme UI T Edition)

Сами API Android 13 (`turnOnTorchWithStrengthLevel`,
`FLASH_INFO_STRENGTH_MAXIMUM_LEVEL`) в системе есть, но многоуровневая
яркость LED включается только тогда, когда её поддерживает драйвер камеры.
У бюджетных Unisoc-устройств (C31 — Tiger T612) драйвер часто сообщает
`MAXIMUM_LEVEL = 1`, то есть физически доступно только вкл/выкл.

В приложении есть карточка **«Диагностика вспышки»**: она показывает на самом
телефоне модель, версию Android/API, ID камеры, максимальное число уровней и
выбранный режим. Кнопка «Тест вспышки» перебирает уровни (или мигает, если
уровень один) — так сразу видно, что реально умеет конкретный экземпляр.

Проверено на realme C31 (RMX3501, realme UI T, сборка RMX3501RU_13.F.89):
Android 13 / API 33, камера 0, `MAXIMUM_LEVEL = 1` — аппаратной яркости нет,
используется ШИМ. Включение и выключение LED при этом подтверждается логами
`CameraService` («Torch for camera id 0 turned on/off»).

- Если диагностика показывает **«Аппаратная яркость: N уровней»** — работает
  плавная регулировка через API Android 13.
- Если **«1 ур. — не поддерживается»** — яркость имитируется ШИМ 80 Гц.

### Подгонка под C31

- Частота дискретизации 44.1 кГц, при отказе — автоматический переход на 48 кГц.
- Источник микрофона: `MIC` → `VOICE_RECOGNITION` → `UNPROCESSED` (что первое
  согласится). На C31 источник 9 (`UNPROCESSED`) открывается, но даёт почти
  тишину, поэтому первым идёт обычный `MIC`. Выбранный источник и частоту
  приложение пишет в logcat (`Light`).
- Удар определяется по атаке: резкий рост общей громкости за кадр больше 0.010
  (при чувствительности ×1.0) и абсолютный уровень выше шумового пола/среднего
  уровня. Поэтому тихая музыка ловится (ползунок поднимает чувствительность), а
  ровный гул и хвост удара — нет. Низкие частоты больше не обязательны.
- Минимальный уровень для удара 0.02, пауза между вспышками 350 мс,
  частота опроса 43 кадра/с.
- Тон ниже 0.015 RMS игнорируется — в тишине экран/вспышка не мерцают от шума.
- Каждый пойманный удар пишется в logcat:
  `beat=N bass=0.123 tone=880Hz gain=0.23`, а раз в секунду — уровень:
  `level rms=0.031 bass=0.014 tone=804` — удобно снимать цифры.

### Измерения на realme C31

Встроенный тест бита (телефон в руке, динамик телефона, микрофон рядом),
три прогона подряд 29.10.2026:

| Прогон | Поймано | Темп | Макс. громкость | Макс. бас |
|--------|---------|------|-----------------|-----------|
| 1      | 16 из 16 | ≈118 BPM | 13 % | 12 % |
| 2      | 16 из 16 | ≈118 BPM | 11 % | 15 % |
| 3      | 16 из 16 | ≈123 BPM | 10 % | 14 % |

Реальная музыка (трек 36 с, громкость телефона 15/16): микрофон видел
громкость 20–32 % RMS, бас 6–16 %, тон 170–1800 Гц, яркость вспышки 17 %,
биты шли ровно по темпу трека (~2 удара в секунду).

Остановка проверена на устройстве по logcat (`AudioRecord: Release`): микрофон
освобождается, когда выключены обе кнопки, а также по Home, Back и при
выключении экрана — меньше чем за секунду. Выключение «Фонарика» при горящем
«Экране» микрофон не трогает: экранный свет продолжает слушать музыку.

### Автотесты DSP

Детектор проверяется без телефона на синтетических ударах:

```powershell
.\gradlew.bat testDebugUnitTest
```

Результаты на 30.10.2026 (9 тестов): 90 BPM — 17 из 18, 120 BPM — 19 из 20,
140 BPM — 23 из 23; тихие удары на уровне микрофона C31 (пик баса 0.12) —
15 из 16; ровный бас 3 с даёт не больше одного бита; тон 440 Гц определяется
с точностью ±3 Гц; в тишине яркость 0. Отдельный тест проверяет, что выбранный
режим «бочка» строже внутреннего «живого баса» (он остался только как эталон
в тестах и в интерфейсе не показывается).

Команда вида `flashlight set-brightness` — это shell/root-инструмент (или
внутренняя команда прошивки), обычному приложению она недоступна. Приложения
управляют вспышкой только через `CameraManager`, поэтому всё, что может
сделать Light, ограничено тем, что разрешает драйвер.

## Ограничения

- Встроенный динамик телефона тоже попадает в микрофон — это нормально, но
  с внешней колонкой эффект стабильнее.
- Настоящая регулировка яркости LED есть только на части устройств
  (Android 13+ с поддержкой strength level). В остальных случаях яркость
  имитируется ШИМ: возможен лёгкий звон/мерцание, а на некоторых прошивках
  частое переключение вспышки может блокироваться — тогда приложение покажет
  ошибку и выключит свет.
- Светодиод греется при длительной работе под нагрузкой — делайте паузы.
- Мерцание света (ШИМ и строб) может быть опасно для людей с
  фотосенситивной эпилепсией.
